打开完整运行与恢复指南 ↗

  1. 准备有权使用的构建

    克隆补丁仓库，导入自行准备的原始文件。六项 SHA-256 必须与基线清单一致，导入工具不会覆盖不同版本。

  2. 按顺序重建本地补丁

    按指南准备 Python 环境与 Noto 字体，再生成中文资源、沙盒资源和原生中文按钮三个阶段。

  3. 启动，然后开始布阵

    已经准备好本地文件的电脑，在项目目录执行：

    ./Start-Local.ps1

    固定地址：http://127.0.0.1:8765/local.html

只克隆代码还不能启动游戏。不要改端口或直接打开 file://，否则资源加载和存档可能不符合预期。

开始前，几个明确的答案。

这是官方版或完整汉化版吗？

不是。它是针对指定编译构建的非官方实验补丁，汉化为部分完成。构建标题不能证明它与 Rappid Studios 手机版属于同一版本，原始游戏也没有在这里被宣称为开源。

资源是严格无限，所有限制都解除了？

不是。宝石在每次启动时补充为大额有限值，游戏依然正常扣费；金币和人数配额扩大，地形、碰撞及性能边界保留。本地可用兵种不代表真实购买或线上解锁。

如何恢复普通模式，存档会不会丢？

在菜单中打开同一地址并加上 ?sandbox=0，即可使用普通模式。普通档与沙盒档分开保存；不要删除浏览器配置或更换本地 origin。完整回滚步骤见运行指南。

为什么网站没有“开始游戏”按钮？

本次公开范围仅为代码、补丁和文档。游戏资产、生成构建与个人存档不会上传到 GitHub 或 Pages；本机已有的游戏仍可正常启动。
